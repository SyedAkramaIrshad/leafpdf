# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use the repository's **Security**
tab to submit a private vulnerability report to the maintainer.

Include the affected version or commit, reproduction steps, impact, and any suggested mitigation.
Avoid attaching real personal PDFs or signatures; use a minimal synthetic file whenever possible.

## Privacy boundary

LeafPDF is designed to process PDFs locally. Any change that sends document bytes, annotations,
signatures, recovery data, or extracted content to another host is a security-sensitive behavior
change and must be disclosed explicitly before it can be accepted.
